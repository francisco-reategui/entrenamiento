# Plan 8 Semanas

App personal de entrenamiento (fuerza en casa + bicicleta ThinkRider con pendiente automática + banda de pulso Magene).

- Se abre en `https://francisco-reategui.github.io/entrenamiento/` con Chrome en Android.
- Se instala desde el menú de Chrome: **Instalar app** o **Agregar a pantalla principal**.
- Los datos de entrenamiento se guardan solo en el celular (Chrome). Este repositorio contiene únicamente el código.
- Bluetooth: banda de pulso (servicio estándar de frecuencia cardíaca) y rodillo (Tacx FE-C sobre BLE / FTMS, potencia ciclista).
